# 👑 GoldRep AI - مدرب اللياقة الذكي بالذكاء الاصطناعي
> **تطبيق ويب تقدمي (PWA) متقدم لعدّ تمارين اللياقة وتحليل الحركة عبر الكاميرا والذكاء الاصطناعي الخفيف (MediaPipe Pose)، مع مدرب صوتي تحفيزي وتصميم فاخر باللون الأسود الملكي والذهبي.**

---

## 🌟 نظرة عامة (Overview)

**GoldRep AI** هو تطبيق رياضي ذكي تم بناؤه ليعمل مباشرة داخل متصفحات الهواتف الذكية (iOS Safari و Android) وأجهزة الحاسوب **بدون الحاجة لتحميل أي تطبيقات من المتاجر وبدون تكاليف سيرفرات**. 

يعتمد التطبيق على خوارزميات الرؤية الحاسوبية الخفيفة في الوقت الفعلي (**On-Device Edge AI**) لقراءة مفاصل الجسم وحساب زوايا التمارين بدقة متناهية مع توجيه صوتي حماسي باللغتين العربية والإنجليزية.

---

## ✨ المميزات الرئيسية (Key Features)

- ⚡ **معالجة فورية على جهاز المستخدم (Zero Latency & 100% Privacy):** تتم معالجة الفيديو محلياً بالكامل عبر تقنية WebAssembly و WebGL دون إرسال أي صور أو فيديو إلى خوادم خارجية.
- 🔊 **مدرب صوتي تفاعلي (Interactive Voice Coach):**
  - نغمة جرس ذهبي رنانة فور إتمام كل عدة صحيحة.
  - نطق رقم العدة فورياً مع عبارات تشجيعية متجددة (*"عاش يا بطل!"*، *"وحش! كمل للعدة القادمة!"*، *"أداء أسطوري!"*).
  - دعم التبديل السلس بين **اللغة العربية** و **اللغة الإنجليزية**.
- 📱 **دعم كامل لعتاد الآيفون (iOS Safari Hardware Ready):**
  - متوافق 100% مع قيود كاميرات WebKit وأبعاد النوتش (Notch) والجزيرة التفاعلية (Dynamic Island).
  - إمكانية التبديل الفوري بين الكاميرا الأمامية والكاميرا الخلفية.
  - دعم التثبيت كتطبيق مستقل (PWA) على الشاشة الرئيسية بدون أشرطة المتصفح.
- 📊 **لوحة مؤشرات حيوية متقدمة (HUD Display):**
  - حلقة تقدم دائرية ذهبية تدور وتتسع مع نزول وصعود المتدرب.
  - حساب تلقائي للسعرات الحرارية المحروقة لكل تمرين حسب شدته.
  - مؤقت زمني دقيق للجولات الرياضية.
  - قياس نسبة دقة الأداء (Form Score %).
  - نافذة ختامية تلخص إنجازات الجولة التدريبية.

## 🏋️‍♂️ مكتبة التمارين المدعومة (12 تمريناً رئيسياً)

تمت برمجة آلات حالة رياضية (State Machines) لحساب زوايا المفاصل بدقة لكل تمرين:

### 🦵 1. الجزء السفلي (Lower Body):
* **سكوات (Squats):** قياس زاوية (الحوض - الركبة - الكاحل).
* **طعنات (Lunges):** رصد نزول الركبة الأمامية والخلفية لحساب الخطوات.
* **الرفعة الميتة (Deadlifts):** رصد انحناء الحوض واستقامة الظهر (Shoulder-Hip-Knee).

### 💪 2. الجزء العلوي (Upper Body):
* **تمرين الضغط (Push-ups):** قياس زاوية المرفق واستقامة الجسم.
* **بايسبس (Bicep Curls):** قياس انثناء الذراع للأعلى والنزول الكامل.
* **ضغط أكتاف عسكري (Overhead Shoulder Press):** دفع الوزن للأعلى فوق الرأس.
* **رفرفة أكتاف جانبي (Lateral Raises):** رفع الذراعين بمستوى الكتف.
* **ترايسبس ديبس (Tricep Dips):** قياس نزول الكوع للخلف وصعوده.

### 🔥 3. البطن والكارديو (Core & Cardio):
* **تمارين المعدة (Crunches):** قياس ثني الجذع نحو الركبتين.
* **رفع الأرجل للبطن (Leg Raises):** قياس رفع الساقين لأعلى من وضعية الاستلقاء.
* **القفز النجمي (Jumping Jacks):** رصد فتح الأطراف ورفع الأيدي فوق الرأس.
* **بلانك ثبات (Plank Hold):** حساب **ثواني الثبات** الفعلي مع مراقبة استقامة الظهر وتشجيع دوري كل 5 ثوانٍ.

## 🛠️ البنية التقنية (Tech Stack)

- **Frontend Core:** HTML5 Semantic Markup, Modern Vanilla JavaScript (ES6+).
- **Styling:** Custom Vanilla CSS3 (Luxury Obsidian & Metallic Gold Theme, Glassmorphism, CSS Custom Properties).
- **Vision AI:** Google MediaPipe Pose via WebGL/WASM.
- **Audio Engine:** Web Audio API (Synthesized Golden Bell Chimes) + Web Speech API (Text-to-Speech Coach).
- **Progressive Web App:** Service Worker Cache API + Web App Manifest (`manifest.json`).

## 📲 كيفية التثبيت على الآيفون والأندرويد (PWA Install)

### لنظام iOS (iPhone):
1. افتح رابط الموقع في متصفح **Safari**.
2. اضغط على زر **المشاركة (Share ⎋)** في أسفل الشاشة.
3. اختر **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**.
4. اضغط **"إضافة" (Add)**. سيتثبت التطبيق فوراً بأيقونة التاج الذهبي الملكي.

### لنظام Android:
1. افتح الرابط في متصفح **Chrome**.
2. اضغط على خيارات المتصفح (الثلاث نقاط) واختر **"تثبيت التطبيق" (Install App)**.
